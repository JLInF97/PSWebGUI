# Show-PSConsole

## SINOPSIS
Muestra la consola de PowerShell.

## SINTAXIS

```powershell
Show-PSConsole
```

## DESCRIPCIÓN
Muestra la ventana de consola de PowerShell actualmente oculta.
Establece la variable ```$GLOBAL:CONSOLE_DISPLAY``` a 1

## EJEMPLOS

### Ejemplo 1
```powershell
PS C:\> Show-PSConsole
```
