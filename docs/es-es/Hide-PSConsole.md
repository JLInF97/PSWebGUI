# Hide-PSConsole

## SINOPSIS
Oculta la consola de PowerShell.

## SINTAXIS

```powershell
Hide-PSConsole
```

## DESCRIPCIÓN
Oculta la ventana de consola actual de PowerShell.
Establece la variable ```$GLOBAL:CONSOLE_DISPLAY``` a 0

## EJEMPLOS

### Ejemplo 1
```powershell
PS C:\> Hide-PSConsole
```
